# doom-js

브라우저에서 돌아가는 **DOOM 엔진 재구현** (바닐라 JS, 의존성 없음). WAD 를 읽어 실제 게임을 플레이할 수 있다.

| WAD | 플레이할 수 있는 것 |
|---|---|
| `DOOM1.WAD` (셰어웨어) | 에피소드 1 (E1M1~E1M9) |
| `DOOM.WAD` (정식판 / 얼티밋 둠) | 에피소드 1~4 전체 (E1M1~E4M9) |
| `DOOM2.WAD` | MAP01~MAP32 전체 (비밀 맵 31·32 포함) |

> 이 저장소에는 게임 데이터(WAD)가 **들어 있지 않다.** 엔진 코드만 있고, 데이터는 직접 준비해야 한다. ([라이선스](#라이선스) 참고)

## 실행

```bash
npm install
# 셰어웨어 DOOM1.WAD (v1.9) 를 public/wad/DOOM1.WAD 에 넣으면 자동으로 읽는다
npm run dev          # http://localhost:5173
```

WAD 를 넣지 않았다면 페이지에서 파일을 끌어다 놓거나 선택하면 된다 (`DOOM1.WAD`·`DOOM.WAD`·`DOOM2.WAD` 모두 가능). 한 번 고른 WAD 는 **이 브라우저(IndexedDB)에만** 저장되어 다음부터는 다시 고르지 않아도 된다 (서버로 전송되지 않는다). 다른 WAD 로 바꾸려면 위쪽 바의 **`WAD 바꾸기`** 버튼이나 **옵션 → CHANGE WAD FILE** 을 누른다.

음악과 효과음은 **기본으로 꺼져 있다.** 위쪽 바의 `음악`·`효과음` 체크로 켜면 그 상태를 기억한다.

```bash
npm run build        # dist/ 생성 (WAD 는 자동으로 제외됨)
npm test             # 게임 로직/전투/저장/규칙/렌더 테스트 (public/wad/DOOM1.WAD 필요)
```

`public/wad/DOOM.WAD`, `public/wad/DOOM2.WAD` 도 있으면 정식판(`tests/registered.mjs`)·둠2(`tests/doom2.mjs`) 테스트까지 돈다. 없으면 그 둘은 건너뛴다.

## 조작

| 입력 | 동작 |
|---|---|
| `WASD` | 이동 (`Shift` 달리기) |
| `←` `→` / 마우스 | 회전 (화면 클릭으로 마우스 시점) |
| `Ctrl` / `F` / 마우스 왼쪽 | 발사 |
| `E` / `Space` | 사용 (문, 스위치) |
| `1`~`7` / 휠 | 무기 교체 (주먹·전기톱, 권총, 샷건·슈퍼 샷건, 체인건, 로켓, 플라즈마, BFG). 둠2 에서 `3` 을 다시 누르면 샷건 ↔ 슈퍼 샷건 |
| `Tab` | 오토맵 |
| `Esc` | 메뉴 (일시정지, 저장/불러오기, 옵션: 소리·마우스·화면 크기·밝기·맵 선택·치트·WAD 바꾸기). 하위 메뉴에는 `< BACK` 버튼이 있다 |
| `F6` / `F9` | 퀵세이브 / 퀵로드 (마지막으로 쓴 슬롯) |
| `R` | 재시작 (맵을 시작했을 때의 상태로). 죽은 뒤에는 `E`(USE)로도 |
| `F1` `F2` `F3` `F4` | 도움말 / 저장 / 불러오기 / 소리 |
| `F7` `F8` `F10` `F11` | 게임 끝내기 / 메시지 켜기·끄기 / 종료 / 밝기 |
| `-` `=` | 화면 크기 줄이기·늘리기 (3~11) |
| `Enter` / `Space` | 결과·이야기·엔딩 화면 넘기기 (둠2 출연진 소개에서는 지금 나온 몬스터를 쓰러뜨린다) |
| 치트 (원작 코드) | `IDDQD` 무적, `IDKFA` 무기·탄약·열쇠, `IDFA` 무기·탄약, `IDCLIP` 노클립, `IDDT` 오토맵 전체 보기, `IDBEHOLD`+`V S I R A L` 파워업, `IDCHOPPERS` 전기톱, `IDMYPOS` 위치, `IDCLEV`+두 자리 (둠1 = 에피소드·맵, 둠2 = 맵 번호) |

`IDKFA`·`IDFA` 는 WAD 에 있는 무기만 준다 (셰어웨어 = 플라즈마·BFG 없음, 둠2 = 슈퍼 샷건 포함). 키보드가 없는 터치 기기에서는 **옵션 → CHEATS** 메뉴로 같은 치트를 쓸 수 있다.

터치 기기에서는 왼쪽 스틱(이동: 원 안은 걷기, 바깥 점선 고리까지 끌어내면 달리기 — 엄지가 빨개지고 안드로이드는 짧게 진동), 오른쪽 스틱·화면 드래그(회전), FIRE / USE / 무기 번호 / MAP / MENU 버튼이 나온다 (데스크톱에서 확인하려면 주소 뒤에 `?touch=1`). 처음 시작할 때 조작 안내가 한 번 나오는데, 여기서 **소리 끄기**와 **시작할 때 전체화면·가로 고정**(기본 꺼짐)을 고를 수 있다. 소리는 나중에도 화면 위쪽 `SOUND` 버튼으로 켜고 끈다. 오토맵에서는 두 손가락으로 확대·축소, 한 손가락으로 이동한다. 앱을 전환하면(전화 등) 자동으로 일시정지되고 AUTO 슬롯에 저장되어, 브라우저가 페이지를 정리해도 타이틀의 `CONTINUE` 로 이어서 할 수 있다. 게임 중 새 게임을 시작할 때는 확인 창이 뜬다.

## 구현 범위

| 영역 | 내용 |
|---|---|
| 데이터 | WAD 디렉터리, 레벨 lump(THINGS·LINEDEFS·SIDEDEFS·VERTEXES·SEGS·SSECTORS·NODES·SECTORS·BLOCKMAP), PLAYPAL/COLORMAP, 패치, 텍스처·flat 합성, 스프라이트 |
| 렌더링 | BSP 앞→뒤 순회, 열 단위 가림 처리, 텍스처 벽·바닥·천장·하늘(에피소드·둠2 맵 구간별), COLORMAP 조명, 스프라이트(8방향·반전), 양면선 투명 텍스처, 픽셀 깊이 버퍼 |
| 게임 | 35Hz 고정 틱, 관성·마찰 이동, BLOCKMAP 충돌과 슬라이딩, 계단·낙하. 원작 1.9 의 선 특수 효과 전부 — 문(열쇠 고속문 포함)·리프트(영구 리프트·멈춤 포함)·바닥·천장·크러셔(짓눌림 피해, 시체는 고깃덩이로)·계단·도넛·조명·텔레포트(텔레프래그·안개, 몬스터 전용 포함)·출구·데미지 바닥·비밀 구역·시간 지나면 열리고 닫히는 문, 애니메이션 텍스처 |
| 전투 | 무기 9종(주먹·전기톱·권총·샷건·슈퍼 샷건·체인건·로켓·플라즈마·BFG), 자동 조준, 히트스캔, 로켓·폭발, 투사체, 통, 드롭, 난이도 5단계(악몽 난이도의 몬스터 부활 포함) |
| 몬스터 | 둠1: 좀비맨·샷건맨·임프·데몬·스펙터·로스트 소울·카코데몬·바론·사이버데몬·스파이더 마스터마인드. 둠2: 체인거너·SS·헬 나이트·레버넌트(유도 미사일)·맨큐버스·아라크노트론·페인 엘리멘탈·아크바일(시체 되살리기·불기둥)·커맨더 킨·아이콘 오브 신(큐브가 몬스터를 부름). 떠다니는 몬스터, 보스 맵 처리(E1M8·E2M8·E3M8·E4M6·E4M8·MAP07·MAP30·MAP32) |
| 저장 | 맵 도중 저장/불러오기(위치·몬스터·문/리프트/크러셔·아이템·오토맵까지), 슬롯 6개(AUTO + 수동 5), 퀵세이브, 맵 이어받기 |
| UI | 원작 상태바·얼굴·무기 스프라이트, 타이틀·메뉴·에피소드 선택·옵션(화면 크기·밝기·메시지·도움말·확인 창·치트), 화면 녹는 전환, 원작 점수 화면(E1~E3 지도, E4·둠2 는 INTERPIC), 에피소드 엔딩(E3 토끼 스크롤 포함), 둠2 이야기 화면과 출연진 소개, 원작 오토맵 규칙(본 선만), 피격·아이템·방사능복 화면 색조, 터치 조작 |
| 오디오 | WAD 효과음(거리·좌우 정위), MUS 음악을 Web Audio 로 합성해 재생 (둠1·둠2 곡 이름 모두) |

타이틀 데모 자동 재생과 멀티플레이는 하지 않기로 했다.

## 구조

```
src/
├─ wad/      WAD·레벨 파서, WAD 저장소(IndexedDB)
├─ gfx/      팔레트, 패치, 텍스처, 스프라이트
├─ render/   BSP 렌더러, 화면 출력
├─ game/     플레이어, 물리, 충돌, 특수 효과, 아이템, 몬스터 AI, 전투, 무기, 세이브(savegame.js)
├─ ui/       상태바, 메뉴, 오토맵, 터치, 점수 화면·엔딩·이야기 화면·출연진 소개(intermission.js)
├─ audio/    효과음, MUS 음악 합성
├─ app/      입력, 저장소(localStorage), 맵 진행 순서·둠2 이야기 화면·곡 이름(progress.js)
└─ main.js   앱 상태와 메인 루프
legacy/      초기 레이캐스터 데모 (참고용)
tests/       시뮬레이션 기반 테스트 (npm test)
```

## 배포

정적 사이트라 Vercel 등에 그대로 올릴 수 있다 (`npm run build` → `dist/`). 빌드 때 `dist/wad`는 지워지고 `.vercelignore`가 `public/wad`를 업로드에서 제외하므로, **배포본에는 WAD 가 포함되지 않고** 방문자가 자기 WAD 를 올려 쓴다.

## 라이선스

- 엔진 코드는 직접 작성했다. 원작 DOOM 소스(GPL)는 구조를 참고했을 뿐 복사하지 않았다.
- `DOOM1.WAD`(셰어웨어)는 id Software 의 저작물이며 별개의 라이선스를 따른다. 이 저장소에 포함하지 않는다. 정식판(`DOOM.WAD`, `DOOM2.WAD`)은 재배포할 수 없다.
