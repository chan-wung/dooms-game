# doom-js

브라우저에서 돌아가는 **DOOM 엔진 재구현** (바닐라 JS, 의존성 없음). 셰어웨어 `DOOM1.WAD`를 읽어 E1M1~E1M9를 실제로 플레이할 수 있다.

> 이 저장소에는 게임 데이터(WAD)가 **들어 있지 않다.** 엔진 코드만 있고, 데이터는 직접 준비해야 한다. ([라이선스](#라이선스) 참고)

## 실행

```bash
npm install
# 셰어웨어 DOOM1.WAD (v1.9) 를 public/wad/DOOM1.WAD 에 넣는다
npm run dev          # http://localhost:5173
```

WAD 를 넣지 않았다면 페이지에서 파일을 끌어다 놓거나 선택하면 된다. 한 번 고른 WAD 는 **이 브라우저(IndexedDB)에만** 저장되어 다음부터는 다시 고르지 않아도 된다 (서버로 전송되지 않는다).

```bash
npm run build        # dist/ 생성 (WAD 는 자동으로 제외됨)
npm test             # 게임 로직/전투/오디오/렌더 테스트 (public/wad/DOOM1.WAD 필요)
```

## 조작

| 입력 | 동작 |
|---|---|
| `WASD` | 이동 (`Shift` 달리기) |
| `←` `→` / 마우스 | 회전 (화면 클릭으로 마우스 시점) |
| `Ctrl` / `F` / 마우스 왼쪽 | 발사 |
| `E` / `Space` | 사용 (문, 스위치) |
| `1`~`5` / 휠 | 무기 교체 (주먹·전기톱, 권총, 샷건, 체인건, 로켓) |
| `Tab` | 오토맵 |
| `Esc` | 메뉴 (일시정지) |
| `R` | 재시작 |
| 디버그: `N` noclip, `K` 열쇠 전부 | |

터치 기기에서는 가상 조이스틱(이동), 화면 오른쪽 드래그(회전), FIRE / USE / GUN / MAP / MENU 버튼이 나온다 (데스크톱에서 확인하려면 주소 뒤에 `?touch=1`).

## 구현 범위

| 영역 | 내용 |
|---|---|
| 데이터 | WAD 디렉터리, 레벨 lump(THINGS·LINEDEFS·SIDEDEFS·VERTEXES·SEGS·SSECTORS·NODES·SECTORS·BLOCKMAP), PLAYPAL/COLORMAP, 패치, 텍스처·flat 합성, 스프라이트 |
| 렌더링 | BSP 앞→뒤 순회, 열 단위 가림 처리, 텍스처 벽·바닥·천장·하늘, COLORMAP 조명, 스프라이트(8방향·반전), 양면선 투명 텍스처, 픽셀 깊이 버퍼 |
| 게임 | 35Hz 고정 틱, 관성·마찰 이동, BLOCKMAP 충돌과 슬라이딩, 계단·낙하, 문·리프트·바닥·계단·조명·텔레포트·출구·데미지 바닥·비밀 구역 |
| 전투 | 무기 6종, 자동 조준, 히트스캔, 로켓·폭발, 몬스터 AI(좀비맨·샷건맨·임프·데몬·스펙터·바론), 투사체, 통, 드롭, 난이도 5단계 |
| UI | 원작 상태바·얼굴·무기 스프라이트, 타이틀·메뉴·옵션, 오토맵, 터치 조작 |
| 오디오 | WAD 효과음(거리·좌우 정위), MUS 음악을 Web Audio 로 합성해 재생 |

셰어웨어 WAD 에 없는 것(플라즈마·BFG, 카코데몬·로스트소울 등)과 크러셔·도넛·영구 리프트는 만들지 않았다.

## 구조

```
src/
├─ wad/      WAD·레벨 파서, WAD 저장소(IndexedDB)
├─ gfx/      팔레트, 패치, 텍스처, 스프라이트
├─ render/   BSP 렌더러, 화면 출력
├─ game/     플레이어, 물리, 충돌, 특수 효과, 아이템, 몬스터 AI, 전투, 무기
├─ ui/       상태바, 메뉴, 오토맵, 터치
├─ audio/    효과음, MUS 음악 합성
└─ main.js   앱 상태와 메인 루프
legacy/      초기 레이캐스터 데모 (참고용)
tests/       시뮬레이션 기반 테스트 (npm test)
```

## 배포

정적 사이트라 Vercel 등에 그대로 올릴 수 있다 (`npm run build` → `dist/`). 빌드 때 `dist/wad`는 지워지고 `.vercelignore`가 `public/wad`를 업로드에서 제외하므로, **배포본에는 WAD 가 포함되지 않고** 방문자가 자기 WAD 를 올려 쓴다.

## 라이선스

- 엔진 코드는 직접 작성했다. 원작 DOOM 소스(GPL)는 구조를 참고했을 뿐 복사하지 않았다.
- `DOOM1.WAD`(셰어웨어)는 id Software 의 저작물이며 별개의 라이선스를 따른다. 이 저장소에 포함하지 않는다. 정식판(`DOOM.WAD`, `DOOM2.WAD`)은 재배포할 수 없다.
